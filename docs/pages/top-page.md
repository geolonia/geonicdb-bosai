# トップページ仕様

作成日: 2026-09-01
関連: [`../REQUIREMENTS.md`](../REQUIREMENTS.md)、[`../research/guidelines.md`](../research/guidelines.md)

## 構成（上から順）

### 1. 緊急バナー

- **常時、ページ最上部に領域を確保する**（GOV.UK方式）。発災時にレイアウトが変わらないよう、平時から同じ位置・同じ高さのコンポーネントとして描画する。
- データモデル: `見出し` / `短い説明` / `リンク1本`（`guidelines.md` 2.3節）
- 重大度バリアント: `緊急安全確保` / `避難指示` / `高齢者等避難` / `注意喚起` / **`お知らせ`（平時のニュートラル状態）**
- 平時のデフォルト表示: 「現在、特別な警戒情報等はありません」（`お知らせ`バリアント、内閣府配色でいう白/中立色）
- 色だけに依存せず、数字・文言を必ず併記する（WCAG 1.4.1）
- 緊急系バリアント（`お知らせ`以外）の動的更新は `role="alert"` / `aria-live="assertive"` を用いる。平時の `お知らせ` は `role="status"` / `aria-live="polite"` とする（WCAG 4.1.3）
- **データソース**: 本ページ実装時点ではモック/静的データで表示し、GeonicDB連携（短TTL JSON API経由のAJAX取得、`REQUIREMENTS.md` 2.1）は後続issueで差し込む

### 2. 警戒レベル表示

- 現在の警戒レベル（1〜5）を色 + 数字 + 文言で表示
- 内閣府公式配色を使用（`guidelines.md` 1.2）
- 黄色（`#F2E700`）は白背景でのコントラスト不足に注意し、文字色・縁取りを規定する

### 3. クイックリンク（4カード）

デジタル庁の4局面をベースに、平時から4つとも表示する。リンク先ページが未実装の間はプレースホルダー（「準備中」）として扱う。

| カード | 対応する局面 | リンク先（後続issue） |
|---|---|---|
| 避難所を探す | 切迫時・応急対応 | 避難所一覧・地図ページ |
| ハザードマップ | 平時 | ハザードマップページ |
| 避難情報 | 切迫時・応急対応 | 避難情報一覧・履歴ページ |
| 防災の備え | 平時 | 平時コンテンツ（持出品・行動計画等） |

### 4. 新着・お知らせ一覧

- 直近の更新（発令・解除等）を新しい順に数件表示
- 各項目に更新日時を明示（「この情報はいつ時点か」が災害時に重要、`guidelines.md` 3.1.G）

### 5. ヘッダー

- 多言語切り替え（`lang`属性を正しく設定、WCAG 3.1.1/3.1.2）。詳細は [`../i18n.md`](../i18n.md)（対応言語は `ja` / `en` / `zh-CN` / `vi` / `ko`）
- ロゴ・自治体名（テンプレートではプレースホルダー）

### 6. フッター

- ウェブアクセシビリティ方針・試験結果ページへのリンク（総務省ガイドライン必須事項、`guidelines.md` 1.8）
- 自治体の連絡先・運営情報（プレースホルダー）
- 印刷対応CSSの適用範囲外（フッター自体は印刷時省略可）

## 非機能要件（このページ固有）

- 1ページのデータサイズは1.6〜3MB以内を目安にする（東京都ガイドライン、`guidelines.md` 1.12(b)）
- 320px幅で横スクロールなし（WCAG 1.4.10）
- 完全静的export対応（`REQUIREMENTS.md` 2.2）。緊急バナー・警戒レベル・新着一覧はクライアントサイドAJAXで取得する前提のマークアップにする（初期実装ではモックJSONを`fetch`する形でよい）

## スコープ外（本issueでは扱わない）

- GeonicDBとの実接続（後続issueでAJAX取得先を実APIに差し替える）
- 4カードのリンク先ページ自体の実装（別issue）
- 新着一覧・避難情報等の運用コンテンツ本体の自動翻訳（[`../i18n.md`](../i18n.md) 参照）
