# 多言語対応 仕様

作成日: 2026-09-01
関連: [`REQUIREMENTS.md`](REQUIREMENTS.md)、[`research/guidelines.md`](research/guidelines.md) 1.10節

## 優先順位

`guidelines.md` 1.10節（在留支援のためのやさしい日本語ガイドライン）と、在留外国人統計（2025年末、上位: 中国・ベトナム・フィリピン、韓国・ブラジルも上位常連）、気象庁の防災気象情報多言語対応（14言語）を踏まえ、以下の優先順位で実装する。

1. **やさしい日本語**（最優先。在留外国人の76%が希望する言語であり、多言語翻訳より優先度が高い）
2. **英語**（実装済み）
3. **中国語（簡体字）・ベトナム語・韓国語**（在留外国人数の上位言語、気象庁14言語とも一致）
4. 任意: ポルトガル語・ネパール語・タガログ語（自治体の実際の外国人住民構成に応じて追加できる設計にする。今回のMVPでは実装しない）

## 現状（issue #3 時点）

- `UI_STRINGS` による文言の言語切替機構は実装済み
- 言語コード: `ja` / `ja-easy` / `en` の3値だが、**`ja-easy` は現状 `ja` にフォールバックしているのみ**（実際のやさしい日本語コンテンツは未実装）
- `document.documentElement.lang` を切替時に更新する仕組みも実装済み

## やること

### 1. やさしい日本語コンテンツの実装（最優先）

- `ja-easy` を `ja` へのフォールバックではなく、**独立した文言セット**として `UI_STRINGS` に追加する
- 対象: 緊急バナー各バリアントの文言、警戒レベルの文言、クイックリンクのラベル、新着一覧の見出し、ヘッダー/フッターの固定文言
- やさしい日本語の作成方針: 出入国在留管理庁「在留支援のためのやさしい日本語ガイドライン」に準拠する簡易ルール（1文を短く、漢字にふりがな相当の配慮は不要だが平易な語彙・能動態を使う、専門用語は言い換えるか括弧書きで補足）。参考: `docs/research/guidelines.md` 1.10節
- 例: 「緊急安全確保」→ やさしい日本語では「今すぐ、安全な場所に行ってください」のように行動指向で言い換える

### 2. 中国語（簡体字）・ベトナム語・韓国語の追加

- 言語コードを `zh-CN` / `vi` / `ko` として `UI_STRINGS` に追加
- ヘッダーの言語切替UIに4言語（やさしい日本語含めると6言語: 日本語/やさしい日本語/English/简体中文/Tiếng Việt/한국어）を並べる。UIが窮屈にならないよう、ドロップダウン形式への変更を検討してよい（現状はボタン横並び）
- 翻訳内容は緊急バナー・警戒レベル・クイックリンク・ヘッダー/フッターの固定文言を対象とする（新着一覧の本文自体は職員が入力する運用データのため翻訳対象外、UIラベルのみ翻訳）

### 3. 言語切替UIの見直し

- 現状はボタン横並び（日本語/やさしい日本語/English の3つ）。6言語になるため、モバイル幅（320px）でも破綻しないUIに変更する（ドロップダウン `<select>` またはメニュー形式を推奨）
- 選択した言語は `localStorage` 等で保持し、再訪問時に引き継ぐ（必須ではないが推奨）

## 非機能要件

- `lang` 属性を言語ごとに正しく設定する（`zh-CN`, `vi`, `ko`, `ja`）。やさしい日本語は `lang="ja"` のままでよい（BCP47には「やさしい日本語」用のサブタグはないため）
- 320px幅で言語切替UIも含めて横スクロールが発生しないこと

## スコープ外

- ポルトガル語・ネパール語・タガログ語（将来追加できる設計にはするが、翻訳文言は今回作らない）
- 新着一覧・避難情報等の運用コンテンツ本体の自動翻訳（別途検討）
