# 多言語対応 仕様

作成日: 2026-09-01
改訂: 2026-09-01（対応言語からやさしい日本語 `ja-easy` を削除）
関連: [`REQUIREMENTS.md`](REQUIREMENTS.md)、[`research/guidelines.md`](research/guidelines.md) 1.10節

## 対応言語（優先順位順）

在留外国人統計（上位: 中国・ベトナム・韓国など）と気象庁の防災気象情報多言語対応を踏まえ、以下を実装する。

1. **日本語**（`ja`）
2. **英語**（`en`）
3. **中国語（簡体字）**（`zh-CN`）
4. **ベトナム語**（`vi`）
5. **韓国語**（`ko`）

任意（今回のMVPでは実装しない）: ポルトガル語・ネパール語・タガログ語など。自治体の外国人住民構成に応じて追加できる設計にする。

> 注: ガイドライン調査では「やさしい日本語」の到達率の高さが指摘されている（`guidelines.md` 1.10）。本テンプレートでは当面 5 言語に絞り、やさしい日本語はスコープ外とする（将来の再追加は言語コード追加と `UI_STRINGS` 拡張で可能）。

## 実装状況

- `SITE_LANGUAGES` / `UI_STRINGS` による文言の言語切替（上記 5 言語）
- ヘッダーは `<select>` ドロップダウン（モバイル幅でも破綻しない）
- `document.documentElement.lang` を切替時に更新
- 動的コンテンツ（緊急バナー・警戒レベル・お知らせ）は GeonicDB 上の `language` プロパティで言語別エンティティを取得（`useLdEntities` + `q: language=="<lang>"`）

### 表示言語の決定順（`usePreferredLanguage`）

1. **`localStorage` の保存値**（`geonicdb-bosai-lang`）— 利用者が明示的に選んだ言語。ブラウザ設定より優先する
2. **ブラウザの言語設定**（`navigator.languages`）— 対応言語に最初に一致したもの（`detectSiteLanguage`）
3. **既定言語**（`ja`）

`matchSiteLanguage` のマッチ規則:

- 完全一致を優先（大文字小文字は無視。`zh-cn` → `zh-CN`）
- 次にプライマリサブタグで一致（`ja-JP` → `ja`、`en-US` / `en-GB` → `en`）
- **中国語は簡体字のみ対応**。`zh` / `zh-Hans` / `zh-Hans-CN` は `zh-CN` に一致させるが、**繁体字（`zh-Hant` / `zh-TW` / `zh-HK` / `zh-MO`）はあえて一致させない** — 簡体字とは別の書記体系であり、防災情報で読みにくい表記を出すより、次の候補言語（例: 英語）や既定言語に委ねる方が安全なため
- 未知の保存値（旧 `ja-easy` 等）は無視し、ブラウザ言語判定へフォールバックする

静的エクスポート（`output: 'export'`）のため判定はクライアントサイドで行う。SSR/ビルド時は既定言語をレンダリングし、hydration 後に上記の順で確定する。

## 非機能要件

- `lang` 属性を言語ごとに正しく設定する（`ja` / `en` / `zh-CN` / `vi` / `ko`）
- 320px幅で言語切替UIも含めて横スクロールが発生しないこと

## スコープ外

- やさしい日本語（`ja-easy`）
- ポルトガル語・ネパール語・タガログ語（将来追加可能な設計にはするが、翻訳文言は今回作らない）
- お知らせ・避難情報等の運用コンテンツ本体の自動翻訳（職員が言語別エンティティを投入する）
